Rord-Mai Calculation API

Use these public calculations from your own application without LINE login. Values are calculated from your request and are not stored in the application database. Do not send names or personal identifiers.

POST /api/v1/calculations/summary for a weighted score, or POST /api/v1/calculations/target with an additional numeric targetPercent.

Request contract

Content-Type: application/json. Supply 1–30 components with unique string IDs (1–100 characters), positive maximumScore, weightPercent greater than zero with at most two decimal places, and score between zero and maximumScore. Use null for an unrecorded score. Weights must total 100. Unknown fields and numeric strings are rejected.

gradingMode is criterion or norm. Criterion requires exactly A, B+, B, C+, C, D+, D thresholds in descending order between 0 and 100. For norm use gradeThresholds: null; letter-grade projections and target calculations are unavailable.

Response

Successful responses wrap results in data. currentWeightedScore is earned percentage points; gradedWeight and remainingWeight are percentages. maximumPossibleScore assumes full marks on remaining assessments. projectedGrade is null until all assessments are recorded. Target adds requiredRemainingPercent, reachable and alreadyAchieved. An impossible target can exceed 100%; no remaining assessments can produce null.

The example returns currentWeightedScore 32, remainingWeight 60 and maximumPossibleScore 92. A target of 80 requires 80% on the remaining assessments.

Limits and errors

16 KiB request limit. Shared limit of 120 requests per minute per server process; other clients consume the same budget. HTTP 429 includes Retry-After seconds. Errors use {"error":{"code":"...","message":"..."}}. Statuses: 400 invalid JSON/input; 413 too large; 415 incorrect content type; 429 capacity reached. Public routes allow browser requests from any origin without credentials. Saved-course and student APIs still require authentication.

JavaScript example

const response = await fetch(base + '/api/v1/calculations/summary', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify(input)
});
const result = await response.json();
if (!response.ok) throw new Error(result.error.message);
console.log(result.data);
